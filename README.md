## 🧐 About the Project

A Windows toolkit that gathers the most important settings in one place. It allows you to manage additional features (DISM), backups, and easy personalization (dark mode, telemetry, etc.).

### Why this project?
* Accessible to people without technical knowledge
* Written in C#, a language that works well with Windows

## 🚀 Getting Started

Instructions on how to set up the project locally.

### Prerequisites

Before you begin, ensure you have met the following requirements:
* [.NET FRAMEWORK 4.8]
* [WINDOWS 11 (I didn't test it on windows10)

### Installation

1. Clone the repository:
   ```bash
   git clone [[https://github.com/](https://github.com/)[your-username]/[repo-name].git](https://github.com/osprivPL/WindowsTOOLKIT.git)
   cd WindowsTOOLKIT/bin/Debug
   WindowsTOOLKIT.exe
   ```
